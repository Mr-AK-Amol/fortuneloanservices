FORTUNE LOAN SERVICES — DOCUMENT UPLOAD INTEGRATION
====================================================

WHAT WAS ADDED
- application.html: a visible "Upload Required Documents" link in the application top bar.
- document-upload.html: responsive bridge page on your website.
- google-apps-script/Code.gs and Index.html: Apps Script web app that receives uploads and saves them to your configured Google Drive parent folder.
- All original project files are included and otherwise preserved.

IMPORTANT: TWO DEPLOYMENTS ARE REQUIRED
1) Deploy the Google Apps Script form
   a. Open https://script.google.com and create a new project.
   b. Copy google-apps-script/Code.gs into Code.gs.
   c. Add an HTML file named Index and paste google-apps-script/Index.html into it.
   d. Check PARENT_FOLDER_ID in Code.gs. It is set to the Drive folder ID previously provided for this project. Make sure that folder belongs to the Google account deploying the script and that the account can create files there.
   e. Save. Run doGet once and authorize the requested Google permissions.
   f. Deploy > New deployment > Web app.
   g. Execute as: Me. Who has access: Anyone (or the broadest access option suitable for your intended applicants).
   h. Copy the deployed Web App URL ending in /exec.

2) Connect the Apps Script URL to the live website
   a. Open document-upload.html.
   b. Find PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE and replace it with the copied /exec URL. Keep the quotes.
   c. Commit and push the complete project to your existing GitHub repository. Vercel should redeploy.
   d. Test the live /document-upload page with a small, non-sensitive test file first.

UPLOAD LIMITS / NOTES
- PDF, JPG, PNG only; maximum 5 MB per file and 8 MB total per submission.
- Each submission creates a uniquely named folder inside the configured Drive parent folder.
- The checklist is indicative, not a lender's final document requirement. Do not upload documents not requested for the application.
- The Apps Script web app must be deployed separately from the Vercel website. Uploading this ZIP alone does not deploy Apps Script or create the live /exec URL.
- Keep the parent Drive folder private. Do not share it publicly.
- The current application inquiry form remains intact; the new upload page is a separate document-upload step.
