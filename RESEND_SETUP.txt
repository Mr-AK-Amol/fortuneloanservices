# Fortune Loan Services — Resend Email Integration

## Email integration
- Website enquiry, partner registration, and referral submissions use the Vercel serverless endpoint `/api/send-email`.
- The endpoint sends email through Resend to `loanservicesfortune@gmail.com`.
- Sender: `Fortune Loan Services <notifications@fortuneloan.services>`.
- The API key is read only on the server from `RESEND_API_KEY`.
- Form fields, validation, conditional sections, WhatsApp message content, and existing page behaviour are retained.

## Vercel configuration
1. Verify `fortuneloan.services` in your Resend account.
2. Create a Resend API key. Never put it in frontend JavaScript or commit it to GitHub.
3. In Vercel → Project → Settings → Environment Variables, add `RESEND_API_KEY`.
4. Enable it for Production (and Preview if needed), then redeploy.
5. Test the loan inquiry, partner registration, and referral forms. Check the Resend activity log and recipient inbox.

## Important
- A successful response means Resend accepted the email request; it does not guarantee inbox placement.
- WhatsApp remains click-to-send: the form opens WhatsApp with the filled message and the user must tap Send.
- This delivery ZIP intentionally excludes `assets/`. Keep the existing `assets/` folder in your deployed project/repository; HTML and CSS still reference those files.
