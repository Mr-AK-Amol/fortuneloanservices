# Fortune Loan Services — Resend Email Integration

## What changed
- Replaced the previous FormSubmit proxy with a Vercel serverless endpoint at `/api/send-email`.
- Website email submissions are sent through Resend to `loanservicesfortune@gmail.com`.
- Sender is `Fortune Loan Services <notifications@fortuneloan.services>`.
- Existing form fields, validation, conditional form logic, WhatsApp message preparation, page design, and asset references are preserved.
- The `assets/` directory is intentionally not included in this ZIP. Keep your existing `assets/` folder beside these files when deploying.

## Vercel setup
1. In Resend, make sure `fortuneloan.services` is verified for sending.
2. Create a new Resend API key. Do not put it in website JavaScript or commit it to GitHub.
3. In Vercel, open the project → Settings → Environment Variables.
4. Add `RESEND_API_KEY` with the new secret API key. Select Production (and Preview if required).
5. Redeploy the project.

## Important
- The API key is read only by `api/send-email.js` on the server.
- The recipient address is fixed server-side as `loanservicesfortune@gmail.com`.
- A successful API response means Resend accepted the message; it does not guarantee inbox placement.
- Test each existing form after deployment. Confirm both the email receipt and WhatsApp flow.
- Do not delete or rename your existing `assets/` directory. This ZIP omits it by request, while keeping all original asset paths in the HTML/CSS.
